# James Lin — Portfolio

Personal portfolio: https://silversnake0.github.io/jdev/

A dependency-free, responsive static site covering AI automation, real estate technology, and selected experiments.

## Structure
- `index.html`: biography, six featured project case studies, credentials, and contact links.
- `assets/css/portfolio.css`: responsive layout, focus styles, and reduced-motion support.
- `assets/James_Lin_Real_Estate_AI_Resume.pdf`: current one-page resume.

Serve locally with `python -m http.server 8793`. GitHub Pages publishes the repository root on `main`.

## Content boundaries
Private implementations are described without source code, internal URLs, or business records. The dashboard capability map is illustrative, not a product screenshot. SpacePlan MR is explicitly in development and simulator-tested, not hardware-certified. The public lease calculator link points to the original calculator, not the private dashboard modules.

Legacy assets are retained but no longer loaded by the new page.
