CapStar Agent Dashboard

One workspace for the moving parts of a brokerage.

The problem

Agents work across documents, spreadsheets, calculations, and shared records. Disconnected steps create repeated data entry and inconsistent workflows.

My contribution

Designed and built a role-based dashboard with agent-specific access, administrator tools, reusable document workflows, and branded reporting. Connected day-to-day brokerage requirements with software implementation and iterative testing.

What it supports

LOIs and forms, lease calculations, CRM records, marketing materials, transaction information, and usage reporting. AI assists selected tasks while agents retain review and decision-making responsibility.

Internal business application. Source code and authenticated systems are not publicly linked.
